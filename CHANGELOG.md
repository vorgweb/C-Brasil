# Cbr 1.0 — versão estável

Esta distribuição reúne os recursos implementados na build de 1.984 linhas do tradutor.

- Funções de usuário com até oito parâmetros numéricos.
- `switch/case/default` com `break`.
- Arrays heterogêneos com capacidade de 256 elementos e suporte a array vazio.
- Alteração por índice, `adicionar`, `remover`, `limpar` e `tamanho(array)`.
- Biblioteca de texto: `contem`, `subtexto`, `substituir`.
- Biblioteca matemática: `raiz`, `absoluto`, `arredondar`, `piso`, `teto`, `seno`, `cosseno`, `tangente`, `logaritmo`, `log10`, `exponencial`, `maximo`, `minimo`, `potencia`, `limitar`.
- Opções de terminal `--help` e `--version`.
- Testes automatizados compilando o tradutor e o C gerado com `-Werror`.

`import` e `try/catch` estão planejados para a Cbr 1.1.
